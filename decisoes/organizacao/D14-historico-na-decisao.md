# A decisão guarda as próprias alterações?  `D14`
Sim, numa seção de histórico ao fim do arquivo.
- Contexto: o texto da especificação não guarda histórico, que fica no controle de versão
- Alternativas descartadas
  - Só no controle de versão, como a especificação: obriga a uma busca para ver como a resolução evoluiu
  - Só a data da última alteração: sinaliza decisão antiga, mas não conta o que mudou
- Consequências
  - Ganha: a evolução de uma decisão se lê num lugar só
  - Aceita: a decisão é a única parte do formato que guarda datas
