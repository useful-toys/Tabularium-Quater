# O que é uma afirmação?  `D18`
Toda linha que pode ser verificada no produto.
- Contexto: o formato usava a palavra tanto para a linha quanto para o texto dela
- Alternativas descartadas
  - Toda linha, inclusive as de modelo: perde-se a distinção com o que se marca como implementado
  - Um nome usado só no texto sobre decisões: dois nomes para a mesma coisa
- Consequências
  - Ganha: afirmação é o que se verifica, se marca e se justifica
  - Aceita: linha continua sendo o termo geral, e a sigla da célula não muda
