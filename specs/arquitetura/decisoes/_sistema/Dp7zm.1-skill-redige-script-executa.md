# Num processo, o que fica com a skill e o que fica com um script?  `Dp7zm.1`
A skill conduz o que pede redação e julgamento, e um script faz o que é mecânico e determinístico.
- Contexto: o resultado de um agente de IA varia de uma execução para outra, e o de um script é sempre o mesmo ⟸ [D01, D96]
- Alternativas descartadas
  - O agente faz tudo, lendo as instruções: validar, indexar, copiar arquivos e contar códigos dariam resultados diferentes a cada execução
  - Um programa faz tudo: perguntar, confrontar uma ideia com o que está escrito e redigir pedem julgamento, que um script não tem
- Consequências
  - Ganha: o que precisa ser exato é exato, e o agente fica com a conversa e a redação
  - Aceita: os processos dependem do Node.js e da permissão para o agente executar scripts
