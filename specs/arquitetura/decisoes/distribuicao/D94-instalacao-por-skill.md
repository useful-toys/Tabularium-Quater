# Como o formato chega ao repositório que o adota?  `D94`
Por uma skill de agente, instalada pelo npx skills.
- Contexto: quem adota o formato já trabalha com um agente de IA e já tem como instalar skills
- Alternativas descartadas
  - Um pacote próprio publicado no npm: exigiria publicar e versionar um pacote só para copiar arquivos
  - Instruções para copiar os arquivos à mão: a cópia manual erra, e ninguém a refaz quando o formato muda
- Consequências
  - Ganha: nenhuma ferramenta de instalação a escrever e manter
  - Aceita: a instalação depende de uma ferramenta de terceiros
  - Aceita: quem não usa agente fica sem caminho de instalação
