# Entre uma solução simples e uma mais completa, qual o formato adota primeiro?  `Dchcx.1`
A mais simples, que é experimentada para se ver o impacto antes de se passar a uma mais complexa e mais completa.
- Contexto: o formato é experimental, e o impacto de uma solução só aparece quando ela é usada
- Alternativas descartadas
  - A solução mais completa desde o início: é adotada antes de se ver o impacto da mais simples
- Consequências
  - Ganha: a solução mais complexa só entra depois de a mais simples mostrar que não basta
  - Aceita: os casos que a solução simples não cobre ficam sem tratamento até a experiência os mostrar
