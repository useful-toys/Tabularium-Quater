# Como se trata um homônimo?  `D53`
Renomeando um dos lados.
- Contexto: palavras que são termos do formato apareciam também com o sentido comum no texto da especificação do próprio formato
- Alternativas descartadas
  - Conviver com os dois significados, marcando cada um: dois sentidos para um termo confundem leitores e agentes
- Consequências
  - Ganha: um termo, um significado ⟸ [D06]
  - Aceita: reescrever frases que usavam a palavra no sentido comum
