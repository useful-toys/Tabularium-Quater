# Uma decisão pode citar outra?  `D20`
Sim, com a mesma marca usada pelos itens da especificação.
- Contexto: dividir as decisões pela questão cria decisões cujo contexto é a resolução de outra ⟸ [D12]
- Alternativas descartadas
  - Cada decisão se basta: o contexto repetido empurra para juntar tudo num arquivo
  - Mencionar o código sem que seja referência conferida: a menção pode apontar para uma decisão já apagada
- Consequências
  - Ganha: contexto escrito uma vez
  - Aceita: a limpeza precisa seguir a cadeia de citações entre decisões
