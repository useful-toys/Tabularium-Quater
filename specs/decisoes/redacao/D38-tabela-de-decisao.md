# Como se escreve uma regra que combina condições?  `D38`
Como tabela de decisão, com cada combinação aparecendo exatamente uma vez.
- Contexto: escritas como várias linhas, essas regras ficam ambíguas e não mostram as combinações que faltam
- Alternativas descartadas
  - Várias linhas de regra: não deixam ver se todas as combinações foram cobertas
- Consequências
  - Ganha: regra densa e verificável quanto à completude
  - Aceita: uma forma a mais na gramática
