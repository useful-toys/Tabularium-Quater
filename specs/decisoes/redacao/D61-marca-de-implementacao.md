# Onde se registra o estado de implementação?  `D61`
Na própria afirmação de regra, qualidade, capacidade, visão ou declaração.
- Contexto: um agente que vai implementar numa base de código grande precisa saber o que falta
- Alternativas descartadas
  - Fora do texto, num rastreador: exige integração e disciplina de citar identificadores
  - Um arquivo de trava, com um resumo de cada afirmação e testes que citam identificadores: forte demais para a primeira versão
  - O controle de versão como estado: exige especificação e código sempre na mesma mudança
- Consequências
  - Ganha: o trabalho pendente é o conjunto das afirmações não marcadas
  - Aceita: cada entrega altera a especificação
