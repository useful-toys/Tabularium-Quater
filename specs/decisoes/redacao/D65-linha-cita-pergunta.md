# Quem aponta para quem, entre a linha e a pergunta?  `D65`
A linha provisória aponta para a pergunta, com uma marca no fim.
- Contexto: quem lê a linha precisa saber que ela é provisória
- Alternativas descartadas
  - A pergunta lista as linhas que afeta: quem lê a linha não vê que ela é provisória
  - As duas pontas se citam: redundância
- Consequências
  - Ganha: linhas provisórias visíveis na própria especificação
  - Aceita: a pergunta sem linha precisa dizer sobre qual célula é
