# Como a regra cita o arquivo de dados?  `D87`
Pelo nome do arquivo entre colchetes, com a definição do link gerada.
- Contexto: as referências a linhas já se escrevem sem link no texto, e todos os arquivos de dados ficam numa só pasta
- Alternativas descartadas
  - Link Markdown com o caminho: repete o caminho em cada citação, pesa na leitura sem renderização e muda quando a área vira pasta
- Consequências
  - Ganha: citação curta, igual em qualquer arquivo da especificação
  - Aceita: a citação só vira link depois de gerada a definição
